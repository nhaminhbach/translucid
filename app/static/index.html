WHY TRADITIONAL OCR / DLP FAILS

Context-blind regex and baseline Cloud DLP over-redact critical evidence (masking 4k/kWh tariffs, meter digits, or commercial appliance stickers like ln7p_5.webp) while under-redacting Zalo/Messenger chat headers and avatars.

OVERCOMING THE SELF-CORRECTION MIRAGE

Naive VLM self-critique loops collapse accuracy from 79.6% to 48.7% (CVPR 2026). Translucid uses Additive Residual Detection (B_final = B_1 U dB): Pass 1 burns solid-black masks; Pass 2 scans strictly for surviving leaks and unions coordinates additively.

UNTRUSTED-WORKER SANDBOXING

Gate 1 pre-tokenizes phones/IDs (<PII_PHONE_01>) before LLM transit. The VLM is physically barred from editing pixels or text—emitting strictly integer [ymin, xmin, ymax, xmax] schemas while deterministic Python executes all mutations.
